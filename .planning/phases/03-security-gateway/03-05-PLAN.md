**mTLS Configuration (mtls.md)** — Replace 7-line stub:

1. **Enterprise admonition**.

2. **"What is mTLS in loxilb?"** (2 paragraphs):
   - Frame: Mutual TLS (mTLS) requires both client and server to present certificates during the TLS handshake. In loxilb, mTLS is configured per load balancer rule for HTTPS FullProxy mode.
   - Key constraint: mTLS only works with security=1 (HTTPS) or security=2 (E2E HTTPS) and mode=4 (FullProxy).

3. **`!!! warning` admonition**: "mTLS requires FullProxy mode (`mode=4`). It has **no effect** in DSR or NAT mode. Source: swagger.yml:6360."

4. **Frontend mTLS** (client certificate validation):
   ```json
   // Source: common/common_mtls.go:34-56 (MTLSFrontendConfig)
   "mtls_frontend": {
     "client_cert_mode": "required",
     "client_ca_path": "/opt/loxilb/cert/client_ca_bundle.crt",
     "require_client_cn": true,
     "client_cn_pattern": "*.corp.example.com"
   }
   ```
   Fields:
   - `client_cert_mode`: disabled / optional / required
   - `client_ca_path` or `client_ca_cert_data`: CA for validating client certs
   - `require_client_cn`: Enforce Common Name matching
   - `client_cn_pattern`: Glob pattern for allowed CNs

5. **Backend mTLS** (server certificate verification):
   ```json
   // Source: common/common_mtls.go (MTLSBackendConfig)
   "mtls_backend": {
     "verify_server_cert": true,
     "backend_ca_path": "/opt/loxilb/cert/backend_ca.crt",
     "client_cert_path": "/opt/loxilb/cert/client.crt",
     "client_key_path": "/opt/loxilb/cert/client.key"
   }
   ```
   Fields:
   - `verify_server_cert`: Validate backend server certificate
   - `backend_ca_path`: CA for verifying backend certs
   - `client_cert_path` / `client_key_path`: Client certificate loxilb presents to backends
   - Also supports inline: `client_cert_data`, `client_key_data`

6. **TLS Version Support**:
   - `!!! note`: "TLS version and cipher suite configuration is managed at the OpenSSL layer in the C data plane (sockproxy). The Go configuration types do not expose TLS version fields directly. Contact support for cipher suite customization requirements."
   - Source confidence: LOW (C layer implementation)

7. **Integration with Load Balancer Rules**:
   - mTLS fields (`mtls_frontend`, `mtls_backend`) are part of the load balancer service rule
   - Applied via `PUT /netlox/v1/config/loadbalancer/{name}`
   - Source: pkg/loxinet/rules.go:338, 877, 2141

8. **See Also**: Secure Dataplane Overview, IPsec, Deployment Scenarios
